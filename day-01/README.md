## 五行参考研究设计

1. **问题** · 510300 的 60 日均线规则在计入交易成本后，能否比同期买入并持有降低样本外最大回撤？
2. **信号** · 每个交易日收盘后，用截至当日的 60 个交易日可比收盘价计算均线。数据齐全且收盘价高于均线时目标为满仓，否则数据齐全时目标为现金。
3. **执行** · 下一交易日开盘尝试用不复权报价成交。信号缺失或无法成交时保留原仓位，记录原因。单边成本初设为成交额的 15 个基点，现金收益暂按零处理。
4. **基准** · 同期买入并持有 510300。双方从拥有足够预热数据后的同一个交易日开始，使用一致的起始资金、分红与费用口径。
5. **判断** · 先冻结数据区间、规则和费用假设，再评估按时间留出的样本外数据。并列报告扣费年化收益、最大回撤与换手，记录失效区间。

## 手算与代码复核

| 模拟价格路径 | 手算结果 |
| --- | --- |
| 收盘价 `2.00 → 2.20 → 1.98` | 两段收益分别是 `+10%` 和 `−10%`，累计收益为 `−1.00%` |
| 收盘后出信号，下一交易日以 `2.06` 买入，再下一交易日开盘价为 `2.08` | 新仓位毛收益为 `2.08 / 2.06 − 1 ≈ +0.97%` |

信号产生时仍为空仓，因此信号当日收盘至实际买入前的涨跌不属于新仓位。运行 [return_demo.py](return_demo.py) 可核对这两个结果。
